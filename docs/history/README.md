# Historical reference material

Imported original technical notes and legacy scripts are preserved to explain provenance and past decisions. They are **not** current device instructions and must not override [status](../status.md) or the [accepted architecture](../architecture/UPSTREAM_POLICY.md). Original external source, OEM material and private logs remain linked or inventoried rather than copied unsafely.

Script revisions in `scripts/history` correspond to diagnostic versions but include intermediate variants and fixes that should not be mistaken for tested releases. The current repository begins with a curated snapshot, not reconstructed Git commits for every historical build.
