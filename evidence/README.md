# Evidence and reproducibility

Evidence is classified as **offline build**, **hash**, **temporary hardware boot**, **physical functional test**, or **feature failure**. Those categories are independent. Raw serial captures remain on trusted hosts, where personally identifying hardware data can be reviewed.

The first public source-of-truth is [v01-v14 checkpoint index](../docs/checkpoints/README.md). Add per-experiment manifests to this directory as sanitized evidence is reviewed. Do not invent physical logs to fill a historical gap.
