### 2026-10-31 — Regulatory source audit: Broadcom country 99 is driver-specific, not a country code
- User asked whether regulatory compliance was addressed during MZ604 Wi-Fi validation. Actual previous `iw reg get` showed **global country 00** and **phy#0 country 99**, with channels **1–11 allowed**, **12–13 NO_IR**, **14 disabled**, and successful WPA association on **2462 MHz / channel 11**, 2.4 GHz. No user regulatory override, 5 GHz probe or 5 GHz transmission. These are technically conservative observations, **not a certification conclusion**.
- **Source-backed clarification**: `include/net/regulatory.h` documents `00` as world domain, `99` as **driver-built custom regulatory domain for which a specific ISO country code cannot be determined**. Mainline `brcmfmac/cfg80211.c` declares `static const struct ieee80211_regdomain brcmf_regdom` with `.alpha2="99"`. Therefore `phy#0 country 99` is **expected brcmfmac behavior**, not proof of wrong region or an unknown regulatory jurisdiction.
